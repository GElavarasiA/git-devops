# Version-Controlled DevOps Project

## Objective
Manage a DevOps project using Git and GitHub best practices.

## Tools Used
- Git
- GitHub
- Visual Studio Code

## Features
- Git repository initialization
- Main, dev, and feature branches
- Pull request workflow
- Commit history management
- .gitignore configuration
- Git version tags

## Branching Strategy
- main: Stable project version
- dev: Development integration branch
- feature: New feature development

## Implementation
1. Initialize the Git repository.
2. Create development and feature branches.
3. Commit changes to the appropriate branches.
4. Push branches to GitHub.
5. Create and merge pull requests.
6. Create a version tag.

## Outcome
Demonstrates basic Git version control and collaboration practices.# git-devops
