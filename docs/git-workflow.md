# Git Workflow Documentation

## Step 1: Repository Initialization
Created a local Git repository and connected it to GitHub.

## Step 2: Branching
Created main, dev, and feature branches.

## Step 3: Feature Development
Implemented the project information page in index.html.

## Step 4: Pull Requests
Pushed the feature branch to GitHub and created a pull request
to merge the feature into dev.

Created another pull request to merge dev into main.

## Step 5: Version Tagging
Created a Git tag named v1.0.0 to mark the first stable release.

## Step 6: Best Practices
Used meaningful commit messages, README.md, and .gitignore.
